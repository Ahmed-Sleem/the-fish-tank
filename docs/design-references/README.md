# Design research and reuse ledger

Reviewed 2026-11-08. Source review, not a claim of visual/device benchmarking.

## Collected source

Paper's [water shader](https://github.com/paper-design/shaders/blob/3f29ea8391addaea459b22caf5e1e8ccabfbd4ee/packages/shaders/src/shaders/water.ts) is saved verbatim as `paper-water.ts.txt`, with upstream LICENSE and NOTICE from that same commit. Apache-2.0; research-only, not imported or served as executable code. Reviewed its six-iteration layered noise, image sampling, GLSL 300 inputs and shader-utils dependencies. It cannot simply be pasted into Pixi. Preserve upstream attribution and review embedded credits when porting. Avoid loading Paper React or a second WebGL canvas just for startup.

## This change

Startup uses original CSS drop squash/stretch and pointer-spawned expanding rings. The adaptation is architectural: a bounded effect pool, disposable listeners, reduced-motion handling and independent readiness gates. No third-party shader code was copied into runtime. This intentionally keeps the loader independent of graphics initialization/failure. Maximum 12 rings; input sampled at 90ms; no extra canvas or requestAnimationFrame loop. Static circular favicon uses Tank's mint/aqua/deep-water palette.

## Required reuse cycle for every following session

Search existing project primitives and upstream implementations; pin source revision; inspect license, maintenance, dependencies, security and browser compatibility; collect only small useful source with notices; study algorithms and failure paths; adapt into existing architecture; test positive and controlled-negative cases; measure actual frame/memory cost; document shipped versus reference-only code. Do not import an entire showcase to obtain one effect. Revisit this ledger at S02, S03 and S04, then inspector/polish sessions.
